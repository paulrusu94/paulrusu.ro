# paulrusu.ro

Personal website of Paul Rusu, senior full-stack developer.

Static site, no build step:

- `index.html` — home page (portrait embedded inline)
- `cv.html` — CV page
- `cv.pdf` — downloadable CV, rendered from `cv.html`

Serve the folder as-is from any static host (Caddy, Cloudflare Pages, Netlify, GitHub Pages).
